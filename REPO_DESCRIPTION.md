## Long-form Description (for Blog/Documentation)

**Title: Powerball-LuckyWeaver: Explore Probability Patterns, Not Predictions**

Powerball-LuckyWeaver is an open-source, interactive tool for exploring lottery number patterns 
through intelligent probability analysis. It's not a prediction system—lottery drawings are 
fundamentally random—but rather a sophisticated exploration of historical patterns and 
personalized number weighting.

**What It Does:**

The tool combines two complementary algorithms:

1. **Decay Weighting** - Numbers that appeared recently have gradually reduced probability 
   in generation. Configurable strength lets you control how much recent draws influence results.

2. **Lucky Numbers** - Select your own lucky numbers and assign custom weights (0.5x to 2.5x multipliers). 
   Combine with decay weighting for personalized generation.

**Why It Matters:**

- **Educational** - Learn probability theory, statistical weighting, and pattern analysis using 
  real data from 1,967+ Powerball draws spanning 2010-2026
- **Transparent** - Open source with no hidden algorithms
- **Accessible** - 5 languages, beautiful responsive UI, zero external dependencies
- **Comprehensive Research** - Includes deep statistical analysis (overlap patterns, position 
  analysis, rolling window trends, odds calculations)

**Key Features:**

- Interactive web application (localhost:5001)
- Multilingual UI (English, Spanish, Portuguese, French, Chinese)
- Batch generation (1-20 combinations at once)
- Real-time visualization of probability weights
- Complete analysis suite with historical pattern research
- API endpoints for programmatic access
- Extensive documentation with guides for every aspect

**Use Cases:**

- **For Fun** - Explore different probability weights and see how distributions change
- **For Learning** - Study probability, statistics, and data analysis with real lottery data
- **For Research** - Analyze historical patterns and test statistical hypotheses

**Built With:**

- Python 3.8+ (NumPy, Pandas, Flask)
- Vanilla HTML5/CSS3/JavaScript (no frameworks, responsive design)
- 1,967+ historical Powerball draws (cleaned and validated)

**Important Disclaimer:**

This is an entertainment and educational tool. Lottery drawings are random and independent. 
No statistical pattern provides predictive power or guarantees any outcome. Play responsibly.

## Technical Description (for Developers)

A full-stack lottery analysis and generation tool featuring:

- **Backend**: Flask server with NumPy-optimized probability algorithms (decay weighting, 
  lucky number multipliers)
- **Frontend**: Responsive vanilla JS/CSS UI with i18n support (5 languages), zero external 
  dependencies
- **Analysis Suite**: Comprehensive Python tools for historical pattern research (overlap analysis, 
  rolling window trends, odds calculations, visualization generation)
- **Data**: 1,967+ historical Powerball draws (2010-2026) in cleaned CSV format
- **API**: JSON endpoints for programmatic generation and data retrieval
- **Documentation**: Complete guides covering features, algorithms, data management, and research

Ideal for probability learners, data scientists exploring statistical patterns, and anyone 
curious about how weighting algorithms work in practice.
