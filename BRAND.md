## Website Description

**Short (1 line):**
"Intelligent Powerball number suggestions powered by probability analysis and historical data."

**Medium (2-3 sentences):**
"LuckyWeaver is an interactive web application that generates intelligent Powerball number combinations using decay-based probability weighting. Based on 16+ years of historical data, it explores patterns while maintaining the understanding that lottery is random. Available in 5 languages."

**Long (full paragraph):**
"LuckyWeaver is a sophisticated yet playful tool for exploring Powerball numbers through intelligent probability weighting. Unlike random selection, LuckyWeaver applies a decay algorithm that gradually reduces the probability of recently drawn numbers, creating more nuanced combinations. Built on analysis of 1,967+ historical Powerball draws, it offers batch generation (1-20 sets), adjustable decay strength, and multilingual support (English, Spanish, Portuguese, French, Chinese). Whether you're a lottery enthusiast exploring patterns, a data scientist studying probability, or simply looking for a more thoughtful approach to number selection, LuckyWeaver makes it fun and educational."
